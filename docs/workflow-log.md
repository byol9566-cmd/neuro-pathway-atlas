## 1. 단계별 타임라인

### 1단계 — 타당성 판단 (2026-09-20 12:46~13:30)

(a) **지시**: 스크린샷 4장(성연의 제안 내용)과 함께
> "실행 가능성 및 힉스필드든 뭐든 활용해야 할 툴들 정리하고 구현 가능성을 판단해봐."

이어서
> "너 나름대로도 한번 서칭해봐 논문이든 뭐든 … 서브 에이전트들은 서칭에만 특화된 haiku나 sonnet 이용하고
> 그 정보의 출처들은 너가 검수해서 믿을 만한 정보인지 확인해서 선별해서 모아."

(b) **수행**: 1차 판단 보고(구현 가능 / 힉스필드는 홍보 영상용 / 3D는 생성이 아니라 공개 아틀라스 라벨 볼륨의 변환) →
Sonnet 서브에이전트 6개를 주제별 병렬 실행(피질하 아틀라스, 뇌간·소뇌·뇌신경, 척수·전도로, 경쟁·시장,
구현 기술, 생성형 3D 검증) → 에이전트 보고의 라이선스·다운로드 위치·DOI를 메인 세션이 1차 출처에서 재확인.

(c) **산출물**: `docs/research-sources.md`(신뢰도 ✅직접검증 / ⚠️에이전트보고 / ❓충돌 표기),
다음 세션 전달용 지시문 `docs/handoff-prompt.md`.

(d) **결정**:
- 3D 모델은 **생성형 AI가 아니라 공개 아틀라스 라벨 볼륨 → 메시 변환**으로 간다. 생성형 3D는 보이지 않는 면을
  지어내고 공통 좌표계가 없어 해부학에 부적합.
- 백본은 **NextBrain(CC0)**. 2차 조사에서 원본 argmax 볼륨(0.2mm, 좌반구, 라벨 333개)을 직접 열어 확인했고,
  1차 조사에서 "시상핵·편도핵이 안 보인다"고 적었던 것은 라벨명이 약어라 놓친 오류로 정정.
- 진짜 병목은 3D가 아니라 **"구조 ↔ 신경과정" DB**(공개 기계가독 DB 없음) → 이 큐레이션이 프로젝트의 핵심 가치.

(d-보충) **사용자가 방향을 지정한 지점**: 조사를 "서브에이전트가 모으고 메인은 출처 검수"로 못박은 것이
이후 모든 작업의 기본 규칙이 되었다.

### 2단계 — 시제품 구현 (2026-09-20 13:30~23:38)

(a) **지시**
> "@docs/handoff-prompt.md 이거 읽고 그대로 진행해줘."
> "그럼 너가 시제품을 어느정도 구현해볼 수 있을까?" → "진행해."

(b) **수행**: Figshare zip에서 필요한 파일만 HTTP Range로 13MB 받아 메시 파이프라인 구축 →
구조 50개(좌우 105 메시, 58만 면)를 14초에 생성, meshopt 압축 후 GLB 3.9MB →
Vite + TypeScript + three.js r186 뷰어에 고스트 셰이더 렌더링, 경로 단계 재생, 검색, 단면 연동 구현.

(c) **산출물**: 커밋 `4587066`(2026-09-20 23:38) — `pipeline/`, `content/`, `viewer/`, `docs/`.
배포 URL https://neuro-pathway-atlas.vercel.app , 저장소 `github.com/byol9566-cmd/neuro-pathway-atlas`(비공개).

(d) **결정**:
- 반투명 렌더링은 OIT·alphaHash 없이 **고스트 셰이더(선택 구조만 불투명 + fresnel 림 + depthWrite:false)**로 충분.
  실제 문제는 정렬이 아니라 확대 시의 "안개"였고, 거리 기반 페이드 + 뇌실 공동 메우기로 해결.
- 개별 메시 105개로 800fps → `BatchedMesh`는 수백 메시 규모까지 불필요.
- NextBrain 청반과 Harvard AAN 청반의 중심 거리 1.36mm → 두 아틀라스를 추가 정합 없이 섞어 쓸 수 있다.
- 극소 핵(동안신경핵 0.4mm³ 등)은 **타원체로 대체하고 화면에 "근사"로 표시**.

**↳ 사용자가 바로잡은 순간 (18:07)**
> "성연에게 컨펌 좀 받게 걔한테도 보여줄 수 있으면 좋겠는데 어떤 방식으로 전달해주지"

질문에 답하기 전에 vite base 경로 수정·빌드를 먼저 돌리려 해서 **도구 호출이 거부**됐다.
이어 "vercel에 띄울까?"로 방법을 사용자가 지정. → 규칙화: **질문에는 답부터, 실행은 요청받은 뒤에.**

## 4. 데이터·라이선스 결정 요약

**채택 — 상업 이용 가능**

| 소스 | 라이선스 | 쓰는 곳 |
|---|---|---|
| **NextBrain** (Casamitjana et al., Nature 2025) | **CC0** | 백본. 원본 argmax 0.2mm·좌반구·라벨 333개에서 메시 추출. 오른쪽은 좌우 반전 |
| **Harvard AAN Atlas v2.0** (Edlow et al.) | **CC0** | 뇌간 각성계 핵. 처음엔 청반·등쪽솔기 2개만, 2026-10-03에 통합 볼륨(핵 10개)을 허락받아 추가 |
| three.js · three-mesh-bvh | MIT | 뷰어 |
| Pretendard · JetBrains Mono | OFL | 서체 |
| 직접 만든 셰이더·SVG·텍스트·타원체 자리표시 | — | 전부 자작 |

**쓰지 않기로 한 것**

- **Tang 2018 뇌간 전도로 아틀라스** — 비상업 전용이고 **파생물 재배포 금지** 문구가 있어 웹 공개 자체가 불가.
- **Petersen 2019 기저핵 경로 아틀라스** — CWRU 소유, 상업 이용에 서면 동의 필요. (렌즈핵고리의 유일한 3D 소스지만 제외.)
- 위 두 건은 2026-09-22에 사용자가 직접 "안 쓸 것 같아"로 결정.
- **MIAL 시상핵 아틀라스**(CC BY-SA) — NextBrain이 CC0로 더 세밀하게 제공하므로 불필요.
- **nervous-system-atlas**(CC BY-SA, 거의 같은 컨셉의 오픈소스) — 포크하지 않고 참고만.
- **FreeSurfer 경유 재배포본·MNI 1mm 재패키징** — 라이선스가 깨끗하지 않고 뇌간 세부가 빠져 있어 빠른 확인용으로만.
- **PAM50(척수)·SUIT(소뇌)** — 라이선스 미기재/충돌로 문의 필요 상태. 척수는 대신 **도식적 자리표시**로 가기로 함.
- **BigBrain · Julich-Brain · Brainstem Navigator · Duke CIVM** — 비상업 또는 확인 불가로 보류.

**오프닝 영상** — motionsites.ai 무료 프롬프트 산출물(사용자 진술). 2026-09-21에 핫링크를 제거하고
H.264 3.7MB로 변환해 자체 서빙하며 사이드바에 출처 표기. 다만 **문서화된 상업 이용 허가는 없음**(사이트에 약관 페이지 없음)
→ 수익화 전에 운영자 문의 또는 WebGL 자체 제작으로 대체.

**강의 정리본 기반 데이터(성연 데이터셋)** — 2026-10-03 사용자 결정: **사용한다.**
- 근거: 문장을 그대로 쓰지 않고, 내용은 교과서 수준의 사실이므로 저작권 문제가 없다는 판단.
- 적용 방식: **뼈대(경로·단계·참여 구조·좌우·교차)는 가져오고, 화면에 나가는 설명 문장은 우리 공개 문헌
  근거로 다시 쓴다.** 정리본 PDF는 받지도, 저장소에 넣지도, 출처 표기에도 쓰지 않는다.
- 주의: 2차적 저작물에는 작성자와 교수의 권리가 겹치므로, 문장을 그대로 쓰려면 양쪽 허락이 모두 필요하다.
  무료 시제품 단계에서는 위험이 낮지만 수익화가 분기점이다.

**근거 인용 자체의 라이선스** — StatPearls는 CC BY-NC-ND. 사실은 근거로 인용해도 되지만
`docs/data/pathway-evidence/`의 인용문은 **검증용 발췌**이며 뷰어에 그대로 싣지 않는다.

  **53개 → 188개**로 갱신됐다(NextBrain 146 · AAN 3 · MNI 타원체 자리표시 39, `aliases.json` 생성).

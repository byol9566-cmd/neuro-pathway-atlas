# 다음 세션 전달용 지시문

아래 내용을 새 세션에 그대로 붙여넣으면 됩니다.

## 배경

의대생 지인(성연)이 제안한 프로젝트의 타당성 조사를 이어서 진행한다. 목표는 웹 기반 3D 신경과학 학습 도구다. 뇌·척수의 세부 구조(개별 시상핵, 뇌간 핵 등)를 각각 독립된 3D 메시로 만들고, 신경과정(반사·감각 경로·인지 회로)을 클릭하면 참여 구조가 하이라이트되고 나머지는 투명해진다. 나는 기술·디자인 담당, 성연은 레퍼런스와 "구조 ↔ 신경과정" DB 담당이다. 수익화는 부차적이지만 가능성은 열어둔다.

## 먼저 읽을 것

`docs/research-sources.md` — 2026-09-20 1차 조사 결과. 출처마다 신뢰도가 표시돼 있다.
- ✅ 직접 검증(1차 출처를 직접 열어 확인)
- ⚠️ 서브에이전트 보고(재확인 안 됨)
- ❓ 출처 간 충돌 또는 라이선스 미기재

이미 ✅로 확정된 내용은 다시 조사하지 말 것. 1차 조사의 결론(3D 모델은 생성형 AI가 아니라 공개 아틀라스 라벨 볼륨에서 메시를 추출한다, 백본은 NextBrain CC0, 힉스필드는 메시 제작에 부적합)은 확정된 것으로 보고 그 위에서 진행한다.

## 작업 방식 (반드시 지킬 것)

1. 검색은 서브에이전트에 맡긴다. 모델은 `sonnet` 또는 `haiku`만 사용하고, 주제별로 나눠 병렬 실행한다.
2. 각 에이전트에게 요구할 것: 1차 출처(프로젝트 공식 사이트, GitHub, Zenodo/OSF/Figshare/NITRC, 논문 본문) 우선, 라이선스 문구는 원문 그대로 인용, 확인 못 한 것은 "unconfirmed"로 표기, 추측 금지, 파일 쓰기 금지.
3. 에이전트 보고는 그대로 믿지 않는다. 라이선스·다운로드 위치·수치·논문 서지 같은 핵심 주장은 메인 세션이 WebFetch로 1차 출처를 직접 열어 재확인한다. GitHub은 `api.github.com/repos/...`, Figshare는 `api.figshare.com/v2/articles/<id>`가 JS 렌더링 페이지보다 잘 열린다.
4. 에이전트 간 정보가 충돌하면 임의로 하나를 고르지 말고 ❓로 분류한다.
5. 1차 조사에서 세션 웹 검색 한도(200회)를 서브에이전트들이 소진했다. 시작 전에 `CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION`을 올려두거나, 에이전트 수와 에이전트당 검색 횟수를 제한한다. 에이전트가 자체 하위 에이전트를 또 띄우지 않도록 지시한다.
6. 결과는 `docs/research-sources.md`를 갱신하는 방식으로 모은다. 새 문서를 따로 만들지 말고, 기존 표의 신뢰도 표기를 승격(⚠️→✅)하거나 항목을 추가·삭제한다. 틀린 것으로 확인된 항목은 지우고 무엇이 틀렸는지 한 줄 남긴다.
7. 충분히 모였다고 판단될 때까지 계속하되, 마지막에 "무엇을 검증했고 무엇이 여전히 미확정인지"를 구분해서 보고한다.

## 이번에 조사할 것

### A. 미확정 항목 확정 (최우선)
- **NextBrain `3dAtlas.zip` 실제 내용**: 이산 라벨 볼륨이 있는지, 어느 공간인지, 전체 라벨 목록. 특히 VPL·VPM·VA·VL·MD 등 주요 시상핵과 편도체 핵이 별도 라벨로 있는지. 1차 조사에서는 커뮤니티 MNI 1mm 재패키징의 LUT 요약만 봤고 이 핵들이 보이지 않았다. 가능하면 readme와 LUT 원문을 확인한다(파일 다운로드가 필요하면 나에게 먼저 물어볼 것).
- **MASSP 2.0 / AHEAD 데이터 라이선스**(논문은 CC BY 4.0, 데이터는 미확인. 타 프로젝트 NOTICE에는 Apache-2.0로 기재).
- **CIT168**(osf.io/r2hvk), **MIAL 시상핵 아틀라스**, **LC metamask**, **spine-generic**, **요천수 아틀라스(Fudan)**, **Allen Human Reference Atlas 3D 2020**: 라이선스와 다운로드 위치를 1차 출처에서 확인.
- **충돌 항목**: SUIT 소뇌 아틀라스(CC BY vs CC BY-ND), HCP-1065 tract atlas(CC BY-SA 4.0 vs HCP 이용약관), BodyParts3D(CC BY-SA 2.1 JP vs CC BY 4.0), Saranathan 2021 시상 아틀라스(Zenodo 레코드 2개), BigBrain 데이터셋 라이선스.
- **비상업 보고 항목의 원문 확인**: Brainstem Navigator, Duke CIVM 뇌간 아틀라스, Tang 2018 뇌간 전도로 아틀라스, Julich-Brain v3.1, FreeSurfer 라이선스.

### B. 공백 영역 — 대안 찾기
- **뇌신경핵**(동안·활차·삼차·외전·안면·전정·달팽이·고립로·의문·미주등쪽·설하)의 3D 위치·형상 데이터: 상업 가능한 공개 소스가 정말 없는지, 좌표·부피를 제공하는 논문(타원체 근사에 쓸 수 있는)이 있는지, WIKIBrainStem과 Rushmore 2020 데이터의 다운로드 가능 여부와 라이선스.
- **공개 아틀라스에 없는 전도로**(안구운동 MLF, 유두시상로, 분계섬유줄, 렌즈핵고리/렌즈핵다발, 시상밑다발): ex vivo 고해상도 트랙토그래피나 PLI 기반 공개 데이터가 있는지.
- **척수 내부 구조**: PAM50 외의 대안, Rexed 층 3D 자료, PAM50 라이선스 문의처(NeuroPoly)와 과거 문의 사례(GitHub issue/forum).
- **수작업 분할용 원본 영상**: Edlow 2019 100µm 7T ex vivo 뇌, BigBrain 뇌간 부위, 기타 공개 고해상도 ex vivo 데이터의 라이선스와 접근 방법.

### C. 구현 기술 — 1차 조사에서 확인 못 한 것
- three.js에서 겹친 반투명 메시 수백 개를 그리는 실전 사례: alphaHash, depth peeling, WBOIT 구현체의 현재 상태, WebGPURenderer의 OIT 지원 여부, 해부학 뷰어들이 쓰는 x-ray/fresnel 셰이더 예제.
- `BatchedMesh`의 개별 피킹 지원 여부, 300~1000 메시 규모의 성능 벤치마크, 모바일 메모리 한계.
- 서로 다른 MNI 템플릿 변형(2009b/2009c/NLin6Asym, CIT168, AHEAD) 간 정합 방법 — TemplateFlow 변환, ANTs 사용법.
- `vtkSurfaceNets3D`의 Python 사용 예제, 경계를 보존하는 감량(decimation) 방법, nii2mesh와의 품질 비교.
- nervous-system-atlas(github.com/aycibatuhan/nervous-system-atlas)의 코드 구조: 메시 생성 파이프라인 스크립트, 경로 데이터 스키마, 렌더링에서 투명도를 어떻게 처리했는지. 포크할지 참고만 할지 판단할 근거를 모은다.

### D. 지식 레이어
- 의대 신경과학 커리큘럼에서 다루는 표준 경로 목록(약 30~100개)을 구성할 근거 자료: 주요 교과서 목차, 한국 의대·KMLE 출제 범위에서 다루는 신경 경로.
- 해부학 용어 체계의 기계가독 버전: Terminologia Neuroanatomica(TNA), UBERON, FMA의 라이선스와 한국어 용어(대한해부학회 용어집) 공개 여부.
- 경로 데이터 스키마 참고용: SCKAN/ApiNATOMY 데이터 모델 문서, nervous-system-atlas의 경로 표현 방식.

### E. 시장·경쟁 (낮은 우선순위)
- 1차 조사에서 확인 못 한 것: atlas-neuro.com의 실제 기능, Visible Body 생리학 애니메이션이 3D 모델과 연동되는지, TeachMeAnatomy 3D의 경로 페이지 동작 방식.
- 한국 의대에서 실제로 쓰는 해부학·신경해부 학습 도구와 기관 구독 현황.

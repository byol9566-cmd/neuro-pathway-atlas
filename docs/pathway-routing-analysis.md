# 경로 재생 선을 "실제 뉴런 주행"으로 바꾸기 — 현황·가능선·필요 데이터 (2026-10-05)

> **1단계 완료(10-05):** HCP1065 미사용 다발 중 19종을 구조로 추가(시상부챗살 3·청각부챗살·겉질선조체 3·치아핵적색시상로(교차는 기하)·SLF 1~3·IFOF·ILF·MdLF·극섬유막·FAT·VOF·PAT·뇌량), 경로 단계 31개에 연결. **실주행 단계 56 → 82(15%), 경로 38 → 57.** 쓰지 못한 다발: 앞맞교차(양측 U자 다발이라 중앙선 무의미), MCP·SCP(좌우 합본), 그물척수로(HCP의 RST는 겉질→숨뇌 겉질그물 섬유로 척수까지 안 감). 
> **2단계 완료(10-05):** 뇌줄기·척수 내부 섬유로 12개를 교과서 단면 위치로 그림(`pipeline/apply_axis_tracts.py`, 검수 표 `docs/data/structures-3d/axis-tracts-review.md`): 가쪽·앞척수시상로, 척수그물로, 삼차시상로, 뒤·앞척수소뇌로, 가쪽·안쪽안뜰척수로, 다리뇌·숨뇌그물척수로, 덮개척수로, 적색핵척수로. 축은 NextBrain 뇌줄기 + Visible Human 척수(+모형 연장), 교차는 z 구간에서 정중선을 건넘. 모형 관(눈돌림신경·척수 기둥 포함)도 이제 중심선을 내보내 재생이 따라감. **실주행 단계 82 → 113(21%), 경로 57 → 79.** 다음은 3단계(뇌신경 경유점 표).

> **3단계 완료(10-05):** 뇌신경 IV·V(뿌리+V1·V2·V3)·VI·VII 말초·큰바위신경·고실끈신경·IX·작은바위신경·X·XI·XII·짧은섬모체신경 — 15개를 교과서 경유점 관으로(`pipeline/apply_cranial_nerves.py`, 검수 표 `docs/data/structures-3d/cranial-nerves-review.md`), 경로 단계 27개 연결. 핵 출발점은 핵 메시 무게중심. **실주행 단계 113 → 140(26%), 경로 79 → 99.** 남은 큰 덩어리는 C(국소 회로 — 연출 설계)와 자율신경 교감 사슬·골반내장신경.

## 지금 어떻게 그리는가
- 경로의 각 단계가 가리키는 구조를 순서대로 잇는다. 구조가 `centerline`을 가지면(신경로·길쭉한 구조) 그 선을 따라가고, 아니면 **무게중심 점 하나**다. 점과 점 사이는 직선(뷰어 `pathways.ts`의 `pathwayRoute`).
- 신경로 메시 자체는 ① NextBrain 라벨(뇌줄기 구간 등 라벨이 있는 곳만), ② HCP1065 트랙토그래피 다발의 중심선 튜브(2026-10-04 추가), ③ 교과서 경유점 관(눈돌림신경) 세 종류.

## 쓸 수 있는 데이터 — 이미 받아 둔 것

|---|---|---|

| CS_A/CS_P/CS_S (겉질선조체) | 바닥핵 직접·간접경로의 겉질→선조체, 선조체 습관·절차기억 | |
| DRTT (치아핵적색시상로) | 소뇌시상 출력, 소뇌적색핵 출력, Guillain–Mollaret | 교차 포함 여부 확인 필요 |
| CPT_F/P/O (겉질다리뇌) | 겉질다리뇌소뇌 경로 1단계 | NextBrain 뇌줄기 구간과 이어 붙여야 함 |

## 데이터가 없는 것 — 세 부류
### A. 아틀라스가 없는 뇌줄기·척수 내부 섬유로 (교과서 기하로 그려야 함)
척수시상로(STT)·척수소뇌로·안뜰척수로·덮개척수로·안쪽세로다발(MLF)·중심피개로·삼차시상로·고립로·내측전뇌다발(MFB)·등쪽세로다발(DLF)·유두시상로(NextBrain 라벨 있음)·올리브소뇌섬유. HCP1065 배포본에 STT·MLF가 없음(Codex 확인). 다른 공개 트랙토그래피(XTRACT·JHU)는 비상업. **방법**: 각 섬유로를 교과서 단면도의 위치(예: STT = 앞가쪽기둥, MLF = 정중선 옆 뒤쪽)에서 뇌줄기 축을 따라 경유점으로 그린다 — 눈돌림신경·가쪽겉질척수로에 이미 쓴 방식(`models.path_tube`, `cord_column`). 뇌줄기 축은 NextBrain 뇌줄기 라벨에서, 척수 축은 Visible Human 척수에서 얻는다. 필요한 입력은 **섬유로별 단면 위치 표**(교과서 Rexed/뇌줄기 단면 — 우리가 작성, 성연 검수).

### B. 말초 주행 (뇌신경·자율신경)
뇌신경 III~XII의 두개 밖 주행, 교감 사슬·백색/회색교통가지, 미주신경, 골반내장신경, 눈물·침샘으로 가는 부교감 섬유. 공개 3D 데이터 없음(Z-Anatomy CC BY-SA 메시가 있으나 품질 미확인, 조사 문서). **방법**: 교과서 경유점 관(눈돌림신경과 동일). 필요한 입력은 신경별 경유점 좌표 표(공·구멍·신경절·표적기관) — Visible Human 절편에서 구멍 위치(위안와틈새·원형구멍·타원구멍·경정맥구멍 등)를 읽어 좌표를 확정할 수 있다(정합 완료 상태라 가능).

### C. 국소 회로·세포 수준 (가장 많음: 자율·학습·세포 분류)
망막 ON/OFF, 소뇌 이끼–과립–평행섬유, 해마 삼중시냅스, 편도 LTP, 미각 변환, 바닥핵 내부(선조체→GPi→시상) 등은 **같은 구조 안**이나 수 mm 거리의 연결이다. 주행 데이터라는 것이 애초에 없고, 매크로 3D에서는 점→점 직선이 오히려 맞다. 대신 ① 구조 내부를 확대했을 때 **도식(2D 회로도)** 을 겹쳐 보여 주거나 ② 구조 표면 위를 따라 흐르는 짧은 호(弧)로 그리는 연출이 적절하다. 데이터가 아니라 디자인 문제.

## 추천 순서
1. (바로) HCP1065 미사용 다발 15종 연결 — 다운로드 없음, 하루.
2. 뇌줄기·척수 내부 섬유로 10여 개를 단면 위치 표로 그리기 — 표 작성 반나절 + 구현 하루. 성연 검수 1회.
3. 뇌신경 경유점 표(III는 끝) — Visible Human에서 구멍 좌표 읽기 포함, 이틀.
4. 국소 회로는 "확대 시 도식" 연출 설계 → 디자인 문서 라운드.

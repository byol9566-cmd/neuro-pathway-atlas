# 근사 자리표시 39개를 세밀한 3D로 바꾸는 방법 (설계, 2026-10-04)

> 진행: 갈래 1 중 안구·망막·각막·뇌하수체·척수(13개 메시) 완료 → `docs/data/vhp-segmentation.md`. 갈래 4 완료: HCP1065 다발 8개가 튜브 구조로 들어가고(겉질척수로 3구간·겉질숨뇌로·시각부챗살·활꼴·갈고리·띠다발) 안쪽섬유띠·아래소뇌다리·뇌활은 중심선만 교체, 경로 16단계가 이를 따라 재생 → `pipeline/tracts/README.md` "아틀라스 반영" 절. 갈래 2·3은 Qwen 좌표 대기.

현재 `content/structures.json`의 `source.atlas == "mni"` 39개는 추정 좌표의 타원체다. 구조마다 **어디서 모양을 얻을 수 있는지**가 다르므로 네 갈래로 나눈다. 모든 결과는 MNI152 공간에 들어가야 하고, 라이선스는 상업 가능(CC0·CC BY·공개 저작물)만 쓴다.

## 갈래 1 — 사진·CT에서 보이는 기관 (18개): Visible Human에서 분할
대상: 눈알·망막·각막·시각신경, 뇌하수체(앞·뒤엽), 솔방울샘, 척수(전체·분절), 달팽이·반고리관·전정(뼈미로), 삼차신경절(Meckel 동굴), 위목신경절·결절신경절(목 연부조직), 경동맥굴·경동맥소체 부근.

- **재료**: NLM Visible Human(남: 1mm 간격 냉동절편 RGB 0.33mm/px + 같은 몸의 CT·MRI; 여: 0.33mm 간격). 라이선스 불필요(NLM 명시: "license is no longer required"), 미국 연방 저작물로 공개 사용 가능.
- **방법**:
  1. VH 머리 MRI(T1) → MNI152 비선형 정합(ANTs SyN 또는 SimpleITK). 이 변환 하나로 VH에서 그린 모든 분할이 MNI로 들어온다.
  2. 냉동절편에서 구조 분할: (a) 눈알·시각신경·척수·뇌하수체·솔방울샘은 색·형태가 뚜렷해 **Segment Anything(SAM, Apache-2.0)** 에 "자리표시 중심을 VH 공간으로 옮긴 점"을 프롬프트로 주고 슬라이스별 마스크 → 쌓기 → ITK 윤곽 보간. (b) 뼈미로(달팽이·반고리관)는 **CT**에서 뼈 안의 액체 공간을 문턱값+연결성분으로 분할(표준 기법). (c) 신경절은 냉동절편에서 수동 보정이 필요 — SAM 초기 마스크를 사람이 슬라이스 몇 장에서 고친다(성연 또는 사용자, 구조당 10~20분).
  3. 분할 → 메시(기존 파이프라인) → `source.atlas: "vhp"`로 등록, 출처 표기 "U.S. National Library of Medicine, Visible Human Project".
- **검증**: 문헌 부피(예: 뇌하수체 0.5~0.9mL, 눈알 지름 24mm)와 비교, Qwen 과제 A의 좌표와 중심 비교.
- **한계**: 한 사람(남 39세·여 59세)의 해부라 개인차가 있음. 뇌줄기 핵은 냉동절편에서 보이지 않으므로 이 갈래로 못 만든다.

## 갈래 2 — 뇌줄기·시상하부 소핵 (약 10개): 모양은 조직 아틀라스, 위치는 MNI 핵 좌표
대상: RVLM·CVLM·거대세포핵·그물덮개핵·침분비핵·Barrington 핵·에딩거-베스트팔(자동 구) 등.

- **위치**: Qwen 과제 A(문헌 MNI 좌표) + AAN v2(CC0, 10개 핵)의 이웃 핵 상대 위치.
- **모양**: Allen 관상 절편 정합본(4차 결과)에서 해당 핵의 **형태만** 가져와(크기·방향 정규화) 문헌 좌표에 놓는다. Allen 콘텐츠이므로 **비상업 꼬리표** — 수익화 시 (a) Allen 허가, (b) 타원체로 환원, 둘 중 하나. 라벨 단위로 `source.atlas: "allen-shape"`를 두어 나중에 한 번에 빼거나 바꿀 수 있게 한다.
- **대안(상업 안전)**: Brainstem Navigator(Bianciardi) 등 공개 7T 확률 아틀라스가 CC BY면 그 모양을 쓴다 — 조사 결과 대기 중.

## 갈래 3 — 척수 내부 (5개): 템플릿 + 도식 압출
대상: 척수 분절, IML, Clarke 기둥, 엉치 부교감핵, 부신경핵.

- 척수 외형: 갈래 1(VH 냉동절편, 경추~흉추 상부는 VH 머리·목 범위에 있음; 그 아래는 VH 몸통 절편 추가 다운로드).
- 회백질 뿔·IML·Clarke: 분절별 **2D 도식(Rexed 층 윤곽)을 직접 그려** 분절 길이만큼 압출. 도식은 교과서(Nieuwenhuys 6장)를 보고 우리가 그린다 → 저작권 문제 없음. 분절 경계 z값은 Qwen 과제 A(척추-분절 대응 문헌)로.

## 갈래 4 — 섬유로 (12개 + 경로 애니메이션)
- HCP1065 트랙토그래피 아틀라스(CC BY-SA 4.0, MNI)의 다발을 **중심선 + 반지름 튜브**로 변환 → `tract: true` 구조로 등록. 경로 재생이 실제 주행을 따라감. SA 조건: 파생 다발 데이터는 같은 라이선스로 공개(우리 메시 파일을 CC BY-SA로 표기하면 됨 — 앱 코드와는 분리).
- 속섬유막 부위·대뇌다리·뇌량 부위는 NextBrain에 없으므로 Allen 정합본(비상업) 또는 HCP1065 다발의 통과 영역으로 근사.

## 순서 제안
1. 갈래 1: VH 머리 MRI+CT+냉동절편(머리 300장, 약 2GB) 받기 → MRI→MNI 정합 → 눈알·시각신경·뇌하수체·척수·뼈미로부터(자동 비율 높음). 가장 큰 효과.
2. 갈래 4: HCP1065 받아(약 1GB) 겉질척수로·안쪽섬유띠·척수시상로·소뇌다리 튜브화.
3. 갈래 2·3: Qwen 좌표 결과와 뇌줄기 아틀라스 조사 결과가 온 뒤.

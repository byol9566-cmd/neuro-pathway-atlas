신경경로 3D 아틀라스 — 내용 검수·작성 시트
뷰어: https://neuro-pathway-atlas.vercel.app  (PC 브라우저 권장)

어디를 고치면 되나요
· '검수', '수정안', '메모', '출처', '중요도' 같은 빈 칸이 채우거나 고칠 칸입니다. 이미 값이 들어 있는 칸은 현재 시제품의 내용이고, 틀렸으면 '수정안' 칸에 적어 주세요.
· 각 시트 아래에 새 줄을 자유롭게 추가하면 됩니다. 확신이 없는 칸은 비워 두거나 '?' 로 두세요.
· 지금 들어 있는 경로 설명과 한국어 용어는 전부 AI가 쓴 초안입니다. 틀린 곳을 찾는 것이 1차 목표입니다.

시트 구성
1_구조   뷰어에 나오는 3D 구조 한 개가 한 줄. '포함할_Allen_구조'에 여러 개를 적으면 하나의 메시로 합쳐집니다(묶기).
2_경로   경로 한 개가 한 줄 (이름·분류·요약·중요도).
3_단계   경로의 단계 한 개가 한 줄. 가장 중요한 시트입니다.
4_병변   경로별 병변 위치 → 증상.
5_참고_Allen라벨   3D로 만들 수 있는 구조 전체 목록(333개, 읽기 전용). 이름은 Allen Human Brain Atlas의 구조명과 같습니다.

칸에 적을 수 있는 값
· 검수: 맞음 / 수정 필요 / 모르겠음     · 좌우·증상_쪽: 같은쪽 / 반대쪽 / 양쪽 / 정중     · 여기서_교차: 예 (아니면 빈칸)
· 뉴런_차수: 1 / 2 / 3 / 4 (해당 없으면 빈칸)     · 중요도: 상 / 중 / 하
· 분류: 체성감각 / 운동 / 뇌신경 반사 / 안구운동·반사 / 시각 / 청각·안뜰 / 자율신경·시상하부 / 소뇌 / 바닥핵 / 둘레계통 / 각성·수면 / 통증 조절 / 고위 겉질 기능 / 척수 반사 / 기타

꼭 지켜 주세요
1. 좌우는 '왼쪽/오른쪽'이 아니라 기시쪽 기준 '같은쪽/반대쪽'으로 적습니다. 뷰어에서 좌우 스위치를 누르면 전체가 뒤집히기 때문입니다.
   예) 뒤기둥-안쪽섬유띠 경로: 기시쪽 = 자극을 받는 몸 쪽 → 널판핵은 '같은쪽', 안쪽섬유띠·VPL·중심뒤이랑은 '반대쪽'.
2. 구조는 구조_id로 가리킵니다(1_구조의 첫 열). 한 단계에 여러 구조면 쉼표로 나열: bs-gracile, bs-cuneate
3. 3D에 아직 없는 구조도 지우지 말고 '메시_없는_구조' 칸에 적어 주세요. 다음에 무엇을 3D로 만들지 정하는 목록이 됩니다.
4. 새 구조를 추가할 때는 5_참고_Allen라벨에서 이름을 찾아 '포함할_Allen_구조' 칸에 그대로 붙여 넣으면 됩니다. 목록에 없으면 이름만 적어 주세요(직접 모델링 후보).
5. 출처는 교과서 이름과 쪽수 정도면 충분합니다. 예) Blumenfeld 3판 p.279

알려진 한계 (틀린 게 아닙니다)
· 오른쪽 반구는 왼쪽의 좌우 반전본이라, 단면에서 좌우 반쪽 사이에 틈이 보일 수 있습니다.  · 뇌활은 가운데(몸통~다리) 구간의 데이터가 없어 경로선이 허공을 잇습니다.
· 눈돌림신경핵·혀밑신경핵은 데이터가 너무 작아 타원체로 대신했습니다('근사').  · 척수, 속섬유막, 말초 구조는 아직 없습니다.
· 부피 참고: 시상밑핵·가쪽무릎핵·둔덕이 문헌값보다 2~3.5배 크게 나옵니다. 눈으로 봐서 너무 커 보이는지 알려 주세요.

파일 여는 법
· Mac: 파일을 더블클릭하면 Numbers로 열립니다.  · 구글 시트: 파일 > 가져오기 > 업로드.  · 계정이 필요 없습니다.
· 고친 뒤에는 CSV로 저장(Numbers: 파일 > 다음으로 내보내기 > CSV)하거나, 시트 파일 그대로 보내 주셔도 됩니다.

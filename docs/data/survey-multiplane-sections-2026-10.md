# Survey: multi-plane annotated sections OR true 3D annotated histology volumes of the human brain (2026-10)

Question driving this survey: the Allen Adult Human Brain Atlas we tried to use only has **coronal** annotated histology plates (106 plates, no inter-plate alignment/registration data) and is **non-commercial**. Does any other human-brain dataset give us either (a) annotated sections in **more than one plane** (sagittal + horizontal + coronal) of the *same* brain, or (b) a **true 3D histology/anatomy volume** (so it can be re-sliced in any plane) **with structure annotations**, under a licence compatible with commercial use?

Method note: most facts below come from direct fetches of primary sources (publisher pages, Europe PMC, NLM, EBRAINS, project sites) and the project's own prior verification in `docs/research-sources.md` (NextBrain, BigBrain `License.txt`, Julich-Brain EBRAINS KG, MASSP/AHEAD figshare records — all previously opened and read directly, not just described). Items I could not open directly this round are marked **UNVERIFIED**. "Commercial OK" means the stated licence, read literally, permits commercial use and derivative works (not that we have tested it in court).

## Notes on verification confidence

- **Solid, directly verified** (primary source opened and read, or already verified earlier in this project and cross-checked again this session): NextBrain (CC0, 333 labels, 5 hemispheres, 10,000 sections, Nature 2025 abstract read directly via Europe PMC), AHEAD/unified-3D-map (CC BY, PMC full text data-availability + licence statement read directly), BigBrain `License.txt` = CC BY-NC-SA 4.0 (already verified in `docs/research-sources.md`), Julich-Brain = CC BY-NC-SA 4.0 (already verified via EBRAINS KG API in `docs/research-sources.md`), Visible Human Project = public domain / no licence required since 2019 (NLM pages + search), Visible Korean Human = CC BY-NC (multiple paper abstracts), Brain Biodiversity Bank = non-commercial/no-redistribution (site text read directly), HCPex = GPL-3.0 (GitHub repo).
- **Discrepancy flagged, needs a human call**: bigbrainproject.org's homepage text claims "CC BY-SA" for "images on this website," which conflicts with the dataset's own `License.txt` (CC BY-NC-SA) that this project already opened directly in an earlier session. The NC version should be treated as authoritative for the actual downloadable data/labels unless someone opens the current `License.txt` again and finds it changed.
- **Marked UNVERIFIED in this report** (not opened directly this session, or only found via a secondary snippet): Mai/Paxinos thehumanbrain.info exact licence (site unreachable — TLS cert errors), BigBrain↔PD25/ICBM152 co-registration licence, SPL/NAC Brain Atlas exact licence text, Chinese Visible Human licence, FreeSurfer thalamic-nuclei-histology-atlas licence, Allen BICAN human MERFISH licence. These should not be relied on for a build/ship decision without a follow-up direct read.
- The user's prompt described "Ahead atlas (Alkemade **2020**, 3D blockface + histology of **1 brain**)" — what was actually found and verified is Alkemade et al. **2022** (*Science Advances*), **2 specimens**. It's possible a distinct 2020 single-brain predecessor exists that this survey did not separately locate; worth a targeted follow-up if the exact 2020/1-brain version matters.

## Conclusion

Two datasets genuinely satisfy criterion (b) — a true 3D histology volume with structure annotations, under a licence that, read literally, permits commercial use — and neither required any compromise on the "annotated, re-sliceable in any plane" requirement:

1. **NextBrain** (Casamitjana & Iglesias, *Nature* 2025) — **CC0**, 333 labelled structures reconstructed from ~10,000 serial histological sections of 5 whole hemispheres into one 3D probabilistic/label volume. This is already this project's data backbone, and is the strongest possible answer to the question: it is simultaneously (a)-like in origin (derived from real serial histology, so it is anatomically grounded like the Allen atlas) and (b) in form (a true re-sliceable 3D volume), with the most permissive licence of anything surveyed.
2. **AHEAD / "unified 3D map" (Alkemade et al., *Science Advances* 2022)** — **CC BY 4.0**, cortex + 17 subcortical structures, reconstructed from ~800 histological sections per specimen (2 specimens) into a 3D blockface/MNI volume at 200 µm. Commercially usable with attribution, and its direct successor "MASSP 2.0/AHEAD" (CC BY 4.0, 35 structures, already in `docs/research-sources.md`) extends the subcortical structure count further.

No dataset surveyed satisfies criterion (a) — multi-plane (coronal + sagittal + horizontal) annotated sections of the *same* brain — with a confirmed commercial-compatible licence. The one classical resource built exactly for that purpose, **Mai/Paxinos's Atlas of the Human Brain / thehumanbrain.info**, could not be reached this session to confirm its licence, but as a commercially published Elsevier/Academic Press textbook product it should be assumed all-rights-reserved pending direct verification. BigBrain is a true 3D volume (so technically answers the volume half of (b)), but both the raw data and the only available structure-label overlay (Julich-Brain) are **CC BY-NC-SA 4.0** — non-commercial — so it is excluded on licence grounds, same as the Allen atlas that started this investigation. Everything else surveyed is either non-commercial (Visible Korean Human, Brain Biodiversity Bank), proprietary/commercial-in-the-wrong-direction (Nowinski, Naidich-style textbooks, Mai/Paxinos presumptively), not histology-based (SPL/NAC, HCP 7T parcellations — useful only if histology grounding isn't required), or not yet a finished whole-brain annotated 3D product (BICAN/Allen MERFISH human atlas, still in progress through ~2027).

**Practical implication for this project:** NextBrain (already adopted) plus the AHEAD/MASSP CC BY 4.0 subcortical parcellations remain the best commercially-usable combination found anywhere in this survey; nothing uncovered here beats or meaningfully extends what `docs/research-sources.md` had already established.
